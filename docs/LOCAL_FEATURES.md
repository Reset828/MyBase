# MyBase 本地功能说明

## 数据库与迁移

应用首次启动时会将 SQLite 数据库迁移至当前 schema。schema v3 新增 `note_revisions`、`bookmarks`、`app_session`、`note_templates`；schema v4 增加模板描述、分类、变量定义与创建时间字段；schema v5 清理已加密笔记遗留的明文修订，并在之后的加密转换时自动清理。迁移采用事务；升级前建议使用应用现有数据库备份功能创建备份。备份/恢复操作作用于整个 SQLite 数据库，因此也包含这些表。

修订触发器仅在更新前后笔记均为未加密状态时保存旧版本；加密/解密转换本身不会产生新修订。schema v5 增加数据库触发器，在普通笔记转为加密状态的同一事务中删除该笔记已有的明文修订；解密后重新编辑才会产生新的普通修订。加密笔记不会通过普通编辑自动保存、会话恢复、修订、模板插入或导出路径处理。

## 编辑与检索

侧栏提供 H1–H6 文档大纲。标签树支持多选，可选 AND（全部匹配）或 OR（任一匹配），并可与关键词组合。编辑器提供编辑、普通预览、Web 预览和分屏。

普通笔记编辑采用短暂防抖保存；退出时再次 flush。写入失败会提示，默认取消退出以保留当前进程中的编辑内容；切换活动标签页时也会尝试 flush。选择放弃更改退出时不再额外遍历编辑器强制写库。会话数据在本机 QSettings 保存，包含未加密打开标签、活动笔记、光标/选区/滚动、编辑模式、查询和标签筛选；运行期间每 10 秒写入一次会话快照，检测到上次未正常退出时会询问是否恢复。自动保存队列中尚未落库的普通笔记正文也会保存在 QSettings，并在恢复后重新排队保存；这部分草稿在 Windows 使用 DPAPI 加密后写入本机 QSettings，只适用于未加密笔记，不能替代数据库自动保存；不支持 DPAPI 的平台不会持久化正文草稿；加密失败会提示用户，旧版本遗留的明文草稿键会在写入时清理。用户选择放弃关闭时会丢弃队列草稿。

## 修订、书签与模板

“工具”菜单提供修订历史（选择一个修订与当前内容比较，或选择两个修订互相比较；支持按行差异高亮并排查看和确认恢复）、当前笔记书签和模板操作。内置模板首次启动时写入模板表；可新建、插入、编辑、复制、导入、导出和删除自定义模板，也可从模板新建笔记。模板变量用 `{{name}}` 标记并按变量名精确替换；每次启动会以不覆盖已有数据的方式补齐缺少的内置模板；内置模板覆盖会议纪要、技术设计、读书笔记、周报与项目计划。自定义模板管理界面支持变量增删改，可设置变量名、默认值与必填属性，并校验变量名唯一性及格式；插入时逐项收集变量并进行必填校验。

## 导出

“文件 → 导出”提供 Markdown、HTML 与 PDF。导出在后台任务执行，可取消并反馈结果；目标已存在时界面会先要求确认覆盖，数据以原子写入方式提交。导出由本机执行，不上传内容。PDF 使用 Qt PrintSupport。大型 PDF 渲染阶段的取消响应受 Qt 文档打印过程限制，取消会在渲染结束后及提交阶段再次检查。

## AI 写作（初版）

AI 菜单提供续写、改写、摘要与大纲请求，并在发送前允许选择选中文本、当前段落或全文；结果可预览后替换目标文本、追加到文末或复制。配置时先输入 HTTPS Chat Completions 请求 URL（例如 `/v1/chat/completions`），再输入 API Key，随后可从同一服务的 `/models` 地址获取模型列表；获取到的模型会持久化并显示在 AI 写作菜单的下拉框中。仅接受 HTTPS；API Key 在 Windows 使用 Credential Manager 保存，接口地址、当前模型和模型列表保存在 QSettings。生成内容先预览，用户确认后才以编辑器可撤销操作应用；请求可以取消。对已解密打开的加密笔记，每次请求前会明确提示正文将发送到第三方服务。请求默认 90 秒超时，可通过服务接口调整（范围 1 秒至 10 分钟）；可配置最多 5 次的指数退避重试（默认 2 次，仅对超时、临时网络失败、HTTP 408/429/5xx 等瞬时错误），并对认证、额度、服务端和网络错误提供分类提示。响应解析支持 SSE、NDJSON、普通 JSON 和纯文本，提取常见 `choices[].delta/message.content`、顶层 `message.content`、`response`、`output_text` 及文本数组；流式内容可预览、取消后丢弃，完成后须由用户确认应用。菜单中可配置最大上下文字符数，超长上下文按头尾保留并标明中段省略；字符限制仅作用于正文上下文，不是整个提示词的 token 精确计量，不同模型的真实 token 额度仍由服务端校验。无法提取内容时只显示响应类型和结构字段，不记录响应正文或笔记内容。当前不支持代理专属配置或请求追溯日志；模型接口兼容性和错误提示仍需在目标服务商环境运行验证。

## 编辑器上下文补全（初版）

编辑器支持 `/` 命令补全（标题、代码块、表格、引用、列表、链接和图片片段），在正文 `#` 后提示已有标签、输入 `[[` 时提示未加密笔记标题，并在代码围栏标记后提示语言；`Ctrl+Space` 可手动触发当前上下文候选。补全候选按标签数据动态加载。此实现已在此前 Windows Release 构建中通过编译，仍未做交互验证；复杂 Markdown 上下文、路径候选及键盘可访问性仍需验收。原有格式操作仍可通过工具栏使用。

## 长文档与异步任务

Markdown 预览和 Web 预览在后台解析；任务只捕获不可变 Markdown 输入，不再捕获编辑器拥有的解析器对象，避免编辑器销毁后后台任务继续访问悬空对象。预览结果在应用前校验当前内容/笔记版本，内容变化后重新安排解析；大于约 64,000 个字符的文档采用更长防抖窗口以减少任务堆积。异步 Web 预览现按笔记 ID 和 Markdown SHA-256 指纹复用已完成的 HTML 缓存；输入变化时指纹不匹配，不会使用旧结果。预览目前仍是整篇重新解析，尚未实现增量块级渲染或真实性能基准。

## 依赖与当前限制

桌面应用需要 Qt 6 Core、Sql、Concurrent、Gui、Widgets、WebEngineWidgets、PrintSupport、Network 和 WebSockets。CMake 最低版本提升到 3.25；配置时 FetchContent 从 Automerge 官方仓库固定提交拉取 C FFI（rust/automerge-c）。构建机需安装 Rustup nightly 工具链和 `rust-src` 组件（Automerge C 在非 Debug 构建中使用 `-Z build-std`），并确保 Cargo/Rustc 可在 `%USERPROFILE%\\.cargo\\bin` 或 `CARGO_HOME` 指定的位置找到。Windows 可执行 `rustup toolchain install nightly --component rust-src`，之后重新配置 CMake。最终运行用户无需安装 Rust，需随应用打包相应 native 依赖。性能基准尚未运行，本仓库文档不声明未经测量的数据。协作主体此前在 Windows/Qt 6.9.3 Release 构建通过；本轮稳定光标协议及近期可靠性改动尚未构建或运行验证。异常恢复已支持普通笔记未保存草稿；草稿在 Windows 使用 DPAPI 加密后写入本机 QSettings，不包含加密笔记；不支持 DPAPI 的平台不会持久化正文草稿；加密失败会提示用户，旧版本遗留的明文草稿键会在写入时清理。最终功能及目标平台验收仍需完成。


## 实时协作（初版，尚待目标环境验证）

桌面端“工具 → 实时协作连接”可将当前未加密笔记连接到 WebSocket 房间。连接前会明确提示正文及后续编辑将同步至服务端；加密笔记会在客户端阻止加入。Automerge C FFI 将 Markdown 存为 Unicode scalar 列表，使用 CRDT 操作合并；Qt WebSockets 负责消息传输。连接端支持断线重连、按房间隔离的本机离线消息队列、服务端确认后清除队列、成员状态和远程选区高亮。远程光标使用 Automerge 稳定游标并映射到 Qt UTF-16 位置，若光标消息早于同步消息到达，客户端会在后续同步合并后重新解析；整数下标仅作旧客户端兼容。只读角色在桌面端禁用编辑，服务端拒绝会改变正文的只读同步操作。服务端以 SQLite 保存邀请 token 的 SHA-256 摘要、角色、过期时间、撤销状态和最新 Automerge 快照；快照在同步更新及连接离开时写入。

CMake 新增独立 `MyBaseCollaborationServer` 目标，服务默认只监听 `127.0.0.1:8765`。可用 `--database <path>`、`--address <IP>`、`--port <port>` 配置监听；`--create-invite <room> --role editor|read-only --expires-hours <1-8760>` 创建邀请，`--revoke-invite <token>` 撤销邀请。创建邀请时只把明文 token 输出一次，应通过可信管理渠道交付。服务端当前使用非 TLS WebSocket；远程部署必须放在启用 TLS 的可信反向代理之后，并限制代理/防火墙访问。不要在公网直接暴露 `ws://`，因为令牌与正文会以明文传输。服务端数据库应按敏感数据备份和保护。

依赖通过 FetchContent 固定到 Automerge 提交 `5bae7757ef7b92c8cd6850def388f22767305ccb`，启用其 `UTF32_INDEXING`；构建机需安装兼容的 Rust/Cargo 工具链。桌面运行环境不需要 Rust，但须分发 Automerge native 库及 Qt WebSockets 所需组件。当前协作实现已在 Windows/Qt 6.9.3 Release 构建通过，但尚未运行或多客户端验收；大文档上的 CRDT diff 成本、极端断网/队列满处理、心跳故障检测及 TLS 反向代理部署、只读对抗性验证以及远程光标体验均需在后续验收中验证，不将本说明当作已通过验证的安全或一致性证明。
